# DEV-014 版本化保护分类

保护策略 v1，规则目录 v1。仅复用 DEV-005 已验证的 npm-exclusive-content v1 / npm 11.19.0；新配置默认没有任何外部启用根。配置显式绑定独占根与支持版本，最大 64 根、64 KiB，原子保存并递增配置版本。

ProtectionPolicy 是文件列表和后续预览的公共分类函数。拒绝身份/大小/流未知、多链接、ADS、reparse、稀疏、压缩、离线、加密、系统对象；拒绝源码、配置、文档、凭据、Agent 数据和显式保护根；拒绝无唯一规则、未知版本、活动/观察未知及 30 分钟内修改对象。只有配置支持的普通缓存内容与索引文件可获得“候选”标签，仍不授予执行权限。

实际合成文件测试覆盖默认关闭、明确开启、配置重载版本、活动与未知、身份缺失、ADS、多链接、近期变化、源码/Agent 路径、相似前缀越界、显式保护、规则版本变化。Protection + Storage 共 4 项通过；原文件仍存在，未调用删除。

文件列表显示该策略分类，基于索引的结果会明确要求预览重新读取。尚未开放的手动/批量按钮将在 DEV-015 接入同一策略，执行时再次检查属于 DEV-016。系统级业务活动无法由目录安静保证，产品执行链路必须增加当前消费者复核，不能仅凭手动会话结束放行。
