# DEV-016 产品执行器

G2/G3 已有实测门槛后新增独立产品 ExecuteApproved 入口，没有把 PoC sandbox 授权用于产品。清单不可变、绑定 5 分钟有效期和上下文指纹；单执行器并发租约与审计主键阻止重复执行。SQLite WAL / synchronous FULL 先持久化清单和逐项 Started，再允许删除，结果落盘失败停止后续项。

每项稳定完整祖先句柄，复核批准根 File ID 和文件身份、时间、属性、数据流与保护结论；同一限制共享写入/删除的句柄上设置 disposition。变化/占用跳过；取消停止尚未开始项。审计文件计入原有运行预算，预算不足不继续删除。启动把 Running 标为 Interrupted，不自动续删。

执行与原有 DeletionSafety 8 项通过，之后增加取消和重启检查，CleanupExecution 4/4 通过。实际合成目录正向删除 1 项，预览后修改与锁定 2 项保留，清单外对象保留；重复执行 SQLite 唯一键拒绝。40 MiB 审计日志预算压力使第二个对象保留。这是预算故障测试，不冒称真实磁盘满（真实满盘证据见 DEV-006）。

UI 关闭会请求取消并等待当前任务结束后再释放数据库/监听器。系统消费者判断无法形成全系统业务锁；以保守活动检查与稳定文件句柄为受控边界，未知场景排除。
