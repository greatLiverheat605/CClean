# DEV-011 会话与活动保护

三工具支持 A 级目录/标签/手动会话，不读取聊天、工具私有数据库、完整命令行或凭据。已有工具能力表继续使用；尚未验证自动进程绑定，因此没有在产品中启用。`ProcessInstance` 使用 PID + UTC 启动时间，无法读取时返回未知，不把 PID 本身当证据。

会话文件最多 2 MiB、1,000 条；已结束记录保留 30 天。原子替换前持久化写入，预算不足拒绝变更，独占文件租约防止同数据目录的会话写入竞争。重启把未结束会话标为中断，结束时间保持未知；明确恢复创建新 ID、新开始时间和来源链接。手动结束中断记录也保留 HasGap，不能清除历史不确定性。

活动快照汇集已登记项目、手动会话及依赖目录。暂停、未扫描与中断会话保持未知；近期目录变化重新保护相关范围。明确结束只改变会话活动信号，不构成清理授权；规则与当前对象复核由后续清理步骤统一执行。

Sessions 两项测试通过，覆盖三工具并发、结束/重启/显式恢复、防重复恢复、PID 实例不相等及未知观察。Release 编译零警告、零错误。

桌面合成流程：依次创建 Codex、Claude Code、ZCode 会话；结束 Codex；退出并重启，后两者显示中断且结束时间未知；选择 ZCode 恢复，新记录和原中断记录同时显示。源 JSON 核对新 ID 与 ResumedFrom 正确。时间按本地时区显示，列表可同时查看全部四条合成记录。三工具实际应用进程识别未声称通过。
