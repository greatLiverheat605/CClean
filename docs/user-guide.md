# CClean 内部测试版使用说明

Windows 11 x64；版本 0.1.5。支持空间盘点、项目观察与专用旧转储清理；原 npm 清理 UI 正向流程及发行验收仍未全部通过。

从开始菜单打开“CClean Internal”。默认安装位置为 `%LOCALAPPDATA%\Programs\CClean Internal`。侧栏“空间与快清”可直接盘点目录，不需要先登记。已测范围与剩余限制见 [个人验收](testing/personal-acceptance.md)。

快速使用：

- 空间盘点：默认 C 盘，也可选项目父目录；每轮最多运行约 30 秒，可以停止 / 继续。最多保留 5 万目录、显示 200 行，达到上限需深入较小目录。统计为按路径逻辑大小，硬链接可能重复，父子行不能相加；不能把它当作可释放空间。链接、云占位和不可访问对象跳过并计数。
- 项目与版本副本：用项目标记发现目录；版本提示只比较同一父目录下的相似名称（如 app-v1 / app-v2 / app-backup），不证明内容重复，不自动删任何源码或整个旧项目。选中后可打开、深入盘点或加入监测。
- 快速清理临时文件：打开 Windows 磁盘清理，由系统列出分类并再次确认；“Windows 存储设置”可查看系统分类。按需保留下载、回收站和仍需要的诊断文件，CClean 不替你自动勾选或确认。
- 预览旧崩溃转储：仅当前用户临时目录 wsl-crashes 的直接 wsl-crash-*.dmp 文件，保留最新时间的全部转储及最近 48 小时文件。不删除 WSL 发行版、项目代码或开发依赖；删除后失去旧故障诊断内容。确认后复用逐项身份 / 占用检查和审计，发生异常即停止；清单 5 分钟有效。
- 常见缓存：只展示已盘点的标准缓存位置，不冒称识别工具自定义缓存；除已验证规则外不提供自动删除。清除开发缓存可能增加下载和下一次构建耗时。

持续监测与既有功能：

1. 在“项目与设置”登记明确的项目或目录。仅扫描登记范围，不会自动扫描整盘；避免登记个人资料或整个用户目录。
2. 等待基线建立。总览分别显示逻辑大小、分配估算与相对基线变化；系统可用量是另一种计量。
3. 在项目详情的“项目会话 → 手动会话”开始 Codex、Claude Code、ZCode 或通用工具会话。重启后的活动会话标中断，恢复会建立新时间段。
4. 在项目详情的“开发时间线”筛选观察时间、工具和依据；方向键选节点，也可用列表。详情可打开当前目录文件。历史不是文件版本，不能回滚。
5. 文件选择或“清理中心”的已启用规则生成预览。未知、源码、凭据、Agent 历史、活动、共享及特殊对象会被排除，全选不能绕过。
6. 如确有专用独占 npm 缓存，先把工具配置指向该专用目录，再登记并确认 npm 11.19.0 与独占前提，最后显式启用此根规则。默认/全局缓存不支持。仅 content-v2 与 index-v5 普通文件可能成为候选，至少保留 30 分钟；当前检测到任何 npm/node 消费者会保守保护。
7. 核对具体清单、候选数量与排除原因。清单 5 分钟有效；确认永久删除后不进入回收站，可能需要联网重建。停止只影响后续项，不能恢复已删除内容。
8. 清理记录区分已记录删除与重启后的观察结果。中断不会自动续删；重新预览后才能再次确认。

本地数据默认位于 `%LOCALAPPDATA%\CClean`。暂停或空间预算不足时索引可能过期；未知量不填成零。详细变化保留最多 7 天/10 万条，会话最多 1000 条。审计不自动删旧记录，达到自身预算后停止清理。

浅色/深色可在侧栏切换。小工作区可以滚动，图最多 500 节点，文件列表每页最多 200 项，预览最多 1000 项。

退出会停止后续清理并等待当前项结束。卸载仅移除安装文件，不删除登记根，也不自动删除本地索引和审计。升级前退出旧版本；旧程序遇到更高版本数据格式会拒绝写入。

限制：三工具只有手动上下文关联，尚无 ETW/USN 进程证实；不能证明全系统无人使用。本机安装、升级、卸载保留数据已通过；未完成的跨环境安装、DPI 与性能验收见 [发行验收记录](testing/release-acceptance.md)。

2026-09-18 / 0.1.3：按用户要求，空间盘点不列出系统文件与系统目录，并拒绝直接选择系统子目录。排除 Windows、Program Files、ProgramData、恢复/引导/回收站范围以及系统属性对象。仅统计允许盘点范围，系统临时清理由 Windows 工具管理。

## 0.1.4 项目会话

打开“项目工作台”，选择项目后进入“项目会话”，自动列出本机支持格式的 Codex / Claude Code 会话；无需先登记。搜索支持项目路径、工具和会话 ID。选择后可查看来源并将项目加入监测；状态未知会继续保护，不等于会话正在运行。ZCode 及未识别格式使用“手动会话”页。左下“已实现功能审计”可打开随包报告，了解全部页面能力、限制与未完成项。

## 0.1.5 项目工作台

启动后先展示项目卡片，合并已登记目录和支持的工具会话工作目录；可搜索名称或路径。相同名称的不同版本文件夹按完整路径区分，系统目录不列出。这不是完整 C 盘扫描；还没发现的项目可通过“空间与快清”盘点或“项目与设置”登记。

点击项目后，四个页签始终使用当前项目：

- 开发时间线：查看已记录的文件变化、归因依据和覆盖缺口。未登记项目不回填离线历史。
- 文件与空间：显示项目内相对路径、大小、增长和保护原因；选中后查看完整路径或转入清理预览。
- 清理位置：打开即只读盘点一批，点击“盘点 / 继续”继续；选目录检查清理资格。默认保护和规则覆盖均不是删除授权，只有复核通过才出现候选确认入口。一次最多检查 1,000 文件，超过上限应选择更小目录。
- 项目会话：只看当前目录范围的自动发现记录及所属登记项目的手动会话。

返回“所有项目”选择其他项目。未登记时可点击“加入持续监测”，此后才开始建立文件历史；不会启用清理规则。
