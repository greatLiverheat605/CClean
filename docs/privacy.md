# 本地数据与隐私

CClean 0.1.6 不内置遥测、云同步或自动上传。监测索引与空间盘点使用文件路径、身份、大小、属性和时间等元数据；**用户主动启动版本比较时，会读取符合条件的普通文件内容**。不同功能的读取与保存范围如下。

| 功能 | 读取与保存范围 |
| --- | --- |
| 项目监测、变化历史和清理审计 | 在本机保存文件路径、身份、大小、时间、规则与操作结果，不将文件内容保存为索引。 |
| 空间盘点与手动项目发现 | 由用户盘点、打开“清理位置”或点击“发现 / 继续”触发；只读取目录、文件元数据及项目标记名称，不读取源码内容。未登记的盘点和发现结果只存在本次运行内存中，不因发现而自动登记监测。 |
| 只读版本比较 | 用户选择另一个版本并开始比较后，读取两侧元数据；同相对路径且需要确认内容的普通文件会在本地逐字节读取。每侧最多盘点 10,000 项、合计最多读取 512 MiB 内容，单次时间预算 30 秒，可取消。原始内容不展示、不写入索引、不上传；相对路径、大小和比较结论仅保留在界面内存。 |
| 手动会话与活动保护 | 保存工具标签、项目及依赖路径、会话名称和开始/结束状态。为保护清理对象会读取运行进程名称；不注入进程，不请求管理员权限。 |
| 会话自动发现 | 读取支持格式的 Codex / Claude Code JSONL 有界前缀，只提取会话 ID、项目路径和时间。前缀可能包含消息字段，正文不展示、不保存、不上传。结果只在内存，默认每 30 秒复查；不访问凭据和工具私有数据库，ZCode 暂不适配。 |
| 界面偏好 | 在本地 `preferences.json` 保存浅色/深色选择和上次成功扫描的项目发现范围；不会保存完整发现清单或比较结果。 |

版本比较隐藏系统对象，并跳过已识别的凭据、Git 元数据、Agent 私有目录、数据库、JSONL 等内容；链接、云占位和无法可靠读取的对象保持未知。敏感识别依赖已知路径、名称和扩展名规则，不保证识别任意文件内的秘密内容。请选择确实需要比较的项目版本范围。

文件路径、发现范围和会话名称可能包含敏感信息。不要将运行数据库、偏好文件、原始诊断、完整路径清单或凭据提交到仓库。复制路径由用户主动触发；没有内置诊断上传入口。具体自动发现范围与上限见 [功能审计](audit/implemented-features.md)。

运行数据默认位于 `%LOCALAPPDATA%\CClean`。详细变化最多保留 7 天/100,000 条；容量不足会暂停采集和清理。审计达到预算后保守停止，不静默丢弃永久删除记录。卸载保留运行数据、界面偏好和所有项目目录；用户可在退出应用并备份所需审计后自行管理本地数据。

Windows 清理入口调用系统工具，由用户在系统界面确认；旧 WSL 转储清理通过本地审计记录，原始崩溃内容不读取、不上传。npm 缓存重新下载由用户的 npm 工具执行，其网络请求受 npm 自身配置与隐私政策约束；CClean 的生产清理执行器不执行缓存目录中的脚本或程序。
