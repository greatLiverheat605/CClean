# 本地数据与隐私

CClean 0.1.0 不内置遥测、云同步或自动上传。索引、变化与审计在本机保存文件路径、身份、大小、时间、规则与操作结果；不读取或保存文件内容作为索引。

手动会话保存工具标签、项目与依赖路径及开始/结束状态。为保护清理对象，会读取运行进程名称；基础版不注入进程，不请求管理员权限。

文件路径和会话名称可能包含敏感信息。不要将运行数据库、原始诊断、完整路径清单或凭据提交到仓库。复制路径由用户主动触发；没有内置诊断上传入口。

运行数据默认位于 `%LOCALAPPDATA%\CClean`。详细变化最多保留 7 天/10 万条；容量不足会暂停采集和清理。审计达到预算后保守停止，不静默丢弃永久删除记录。卸载保留运行数据与所有登记目录；用户可在退出应用并备份所需审计后自行管理本地数据。

npm 缓存重新下载由用户的 npm 工具执行，其网络请求受 npm 自身配置与隐私政策约束。CClean 的生产清理执行器不执行缓存目录中的脚本或程序。
