历史截点保留：09-20 16:23:31 时为约 17 小时 45 分、2,130 样本、工作集峰值 176.98 MiB、CPU 0.03880%，数据增至 3,188,437 B；当时“尚未满 24 小时”的判断仅适用于该截点。完整结果以独立审计 `artifacts/performance/product-016/stability-24h-audit-20260922.json` 为准。

npm 正向 UI 仍待独立 Windows 客户机：2026-09-20 的只读检查发现本机 11 个 Node 消费者并触发保护，隔离应用数据不隔离宿主进程或自动发现会话。没有关闭用户消费者、伪造无活动上下文或放宽规则。仍只有专用独占 npm 11.19.0 缓存、旧 WSL 转储规则；未增加任意缓存或旧版本目录删除。
